¿Cómo hago esto? Guía rápida (haz clic para verla)
  1. Agregar un socio nuevo: pestaña Socios → botón Nuevo socio. Escribe su nombre, correo, contraseña y (opcional) teléfono. Listo.
  2. Llenar los datos de un año: pestaña Por año → elige el socio a la izquierda y el año arriba. Si es la primera vez que llenas ese socio, primero toca + Agregar primer año. Luego usa los botones + Agregar para poner cada concepto (obligaciones), cada pago (aportaciones) y los totales. Los botones Editar/🗑 corrigen o borran.
  3. Enviar el estado de cuenta por WhatsApp: pestaña WhatsApp → elige Todos los años o un año → toca Compartir PDF junto al socio. Hazlo desde tu celular: se generará el PDF y la hoja de compartir te lo adjuntará en WhatsApp (elige el contacto). Se envía el archivo, sin enlaces.
  4. Que los socios vean lo nuevo: toca Descargar data.json, reemplaza el archivo con ese nombre y súbelo a GitHub (así como haces para publicar cualquier cambio de la página).
  5. Por seguridad, estos cambios viven en este navegador hasta que se publiquen con el paso 4.
